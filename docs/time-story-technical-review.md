# 시간 이야기 — 기술 검토와 확정 변경

갱신일: 2026-09-12. 테스트는 실제 TypeScript 시스템을 Vite SSR과 Pinia로 불러 실행했다. 통제한 월드 상태의 회귀 검사이며, 시작부터 모든 길을 걸어 진행한 플레이를 뜻하지 않는다.

## 이번에 다시 확인한 조건

`node scripts/test-time-endings.mjs` — 현재 변경본에서 12개 그룹 통과.

- 이전의 불완전한 결말을 기록한 뒤 시작한 새 여정에서 해당 카오스를 선택해야 세 번째 방법의 자격이 생긴다. 진행 중인 첫 여정에 카오스를 덧붙여도 자격이 생기지 않는다.
- 동행을 청할 때 실제 NPC의 생존·거리·시야·상태·신뢰·아크 승리를 확인한다. 중복 영입을 막는다.
- 동행은 선택 사항이다. 두 방법을 엮는 선택과 카오스 자격이 유효하면, 혼자 가거나 동료가 다른 장소에 남아 있어도 진 엔딩이 가능하다. 던 또는 티프레의 실제 사망은 불완전한 결말로 이어진다. 단순 부재·미영입·행방 미상은 사망으로 간주하지 않는다.
- 영입한 동료는 실제로 같은 장소에 있고 행동할 수 있을 때만 지원한다. 지원 없이 혼자 싸울 수도 있다.
- 승리 순간의 현장·부재·사망·행방 미상과 동행 여부를 저장한다. 없는 인물이 엔딩에서 갑자기 나타나 행동하거나 말하지 않는다. 나중에 NPC 상태를 바꾸어도 지난 엔딩은 바뀌지 않는다.
- 결말·카오스 해금·플레이 기록을 저장하며, 결과 흡수를 반복해도 보상을 중복 지급하지 않는다.
- 활성 저장 복원 시 동료·지원 재사용 시간·사망 상태를 보존한다.
- 마지막 한 턴의 마비도 지원을 막고, 티프레의 원거리 지원은 유령의 원거리 면역을 따른다.
- 가까운 동료는 같은 개체로 출구를 통과한다. 멀리 있는 동료를 소환하지 않는다.

`node scripts/test-field-color-actions.mjs` — 현재 변경본에서 11개 그룹, 16개 조작 모두 공통 엔진 실행 통과.

수분과 열의 반응, 절연에 따른 실제 전격 피해 감소, 경도 저항, 흙의 통행 변경, 질량·벽을 따르는 바람 이동, 빛·주의의 실제 생산 돌봄, 수면·각성, 장막의 시야 차단, 목격자의 위험 판단, 마나·재료 거래의 원자성, 기록물의 일반 읽기를 확인했다. [조작과 소비처](color-operations.md)에 구체적인 범위를 적었다.

공개 입력 경로인 `node scripts/test-field-color-input.mjs`는 20개 그룹이 통과했다. 마나 소모·30초 진행·두 턴 회복과 저장, 거절 시 빈 바닥 생성까지 막는 원자성, 거리·다른 맵·시야·상태 제한, 바람·보행·이동기·시간 경과의 실제 설치물 접촉을 확인했다. 최대 HP 450인 마물의 마지막 HP 1 처치, 최종 부탁 전 조율 차단, 유령 원거리 면역도 포함한다. 사람에게 가한 수면·구속·강제 이동은 목격자의 판단에 남고, 자가 작용·마물 전투·각성·방어·실제 연고 치유는 위해로 오인하지 않는다. 기존 공통 세계 13개와 60턴 사회 시뮬레이션도 통과했다.

`node scripts/test-field-boss-gates.mjs`는 8개 그룹이 통과했다. 부탁 수락 전 진입·공격과 오래된 교전 저장을 차단하고, 수락 후 대화·직접 공격·시전·공격자가 있는 지속 상태는 허용한다. 보스 환경 면역과 화면 밖 HP 1 보스의 생존, 일반 마물의 환경 피해도 확인했다.

320×640·390×844 브라우저에서 조율 메뉴와 드래그를 확인했다. 390×844에서는 실제 빗금 드래그로 절연을 실행했다. 메뉴 열기·닫기·조율 모드에서 7×9 격자의 63칸과 높이 479px가 유지됐다. 전체 전투 연출 검수나 장시간 터치 플레이를 대신하지 않는다.

새 플레이 시뮬레이션은 던·티프레 일반 결말, 카오스 두 사람 동행, 카오스 독행, 던 실제 사망 후 독행의 5개 경로가 모두 통과했다. 각 경로에서 입문 4개와 본편 20개를 실제 게임 함수로 완료했다. 일반 최종전은 108턴, 동행 카오스는 95턴, 독행·사망 카오스는 162턴이었다. 장거리 이동과 성장 준비를 생략한 통제 실행이고, 사망 경로는 기본 타격 12회로 만든 예외 조건이다. 일반 플레이의 클리어율이나 전 구간 도보 난도는 아니다. 상세 조건과 남긴 어색함은 [플레이 보고서](time-story-playtest.md)의 후속 검증에 있다.

## 이전 위험 판정의 처리

| 이전 검토 항목 | 사용자가 확정한 변경 | 현재 확인 상태 |
| --- | --- | --- |
| 이야기를 마치기 전에 최종 보스를 처치해 일반 클리어만 기록할 수 있음 | `time-20` 수락 전에는 최종 보스 전투에 진입할 수 없음 | 입장·직접 공격·조율·기존 교전 저장 복원 차단 검사 통과 |
| 두 방법을 고른 뒤 동료 사망으로 필수 영입 목표가 막힐 수 있음 | 동행은 선택 사항으로 변경. 실제 던·티프레 사망만 불완전 결말에 반영 | 필수 영입 목표 제거 확인. 미영입·부재·행방 미상·실제 사망의 결말 회귀 검사 통과 |
| 멀리 떨어진 동료 때문에 진 엔딩이 뒤집힘 | 진 엔딩의 동일 맵 도착 조건 제거. 위치는 지원과 엔딩 출연에만 사용 | 결말 및 현장 기록 검사 통과. 장거리 동행의 체감은 재시뮬레이션 대기 |
| 없는 NPC가 고정 엔딩에서 행동하거나 말함 | 승리 순간의 개체 상태에 맞춰 주인공 행동·동료 출연·사망 문장을 구분 | 모든 결말의 현장/부재/사망/미상 조합과 과거 저장 검사 통과 |
| 환경 지속 피해로 화면 밖 보스를 처치할 수 있음 | 보스·아크는 환경 피해에 면역. 전투 주체의 공격은 별도 | 환경 화재·전류·충격·화면 밖 정산 면역과 공격자 직접 공격·지속 상태의 구별 검사 통과 |
| 기록 세 개가 물이라는 정답만 요구함 | 물 조건 제거. 기록은 평범하게 읽고, 물질 조작은 공통 COLOR 상호작용으로 확대 | 기록 23개 일반 읽기와 16개 공통 조작 검사 통과 |

이 표는 이전 판정을 조용히 삭제하지 않고, 새 결정으로 해결한 부분과 아직 실행 확인이 필요한 부분을 구별한다. 보스 면역과 선행 잠금은 사용자가 이번에 정한 전투 규칙이다. 공통 물성 엔진의 모든 대상이 무조건 같은 피해를 받아야 한다는 요구로 확대 해석하지 않는다.

## 남은 검토

첫 선택이 중간 진행에 주는 영향, 카오스 재도전의 이야기상 근거, 이름 없는 피해자에 대한 감정적 설득력, 조사·보고 왕복의 반복은 별도 서사 검토로 남긴다. 사용자가 수정 방향을 확정한 항목 외에는 원고를 임의로 고치지 않는다.

플레이 클리어율을 60%로 맞추려던 목표는 철회했다. 이 결정은 플레이 난도에 관한 것으로, [포팅 목록](porting-checklist.md)의 기능 완료 여부와는 별개다.

전체 전투 연출의 모바일 검수, 정상 시작 장비로 성장하며 전 구간을 걸어 진행하는 난도, 장거리 동행의 체감은 남아 있다. 완료한 5개 경로 시뮬레이션의 통제 조건과 실제 전 구간 플레이를 구별한다.
