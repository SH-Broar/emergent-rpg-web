# 필드 포팅 목록

기준: 2026-09-12, 기존 grid-combat/combat 및 현재 field-simulation 비교.
실제 실행 데이터: 장소 275, 몬스터 160, 보스·아크 4, NPC 57, 카드 702, 유물 297, 아이템 85, 장비 9, 사건 180, 단서 17. 카드·유물·아이템에는 실행 시 합성되는 8종씩이 포함된다. 데모 파일까지 읽으면 보스는 5종이다.
이전의 이벤트 649는 변형이 별도 항목으로 중복 로드된 수였다. 부모 사건 174개로 바로잡고 끊어진 NPC 사건 6개를 복구했다. 재현: node scripts/audit-port-data.mjs.

기능 포팅은 필드에서 실행하고 검증한 경우에만 완료로 표시한다. 조사 항목의 완료는 기능 지원을 뜻하지 않는다. 순서대로 작은 배포 단위로 처리한다.

사용자 후속 지시로 철회한 것은 플레이 클리어율 60% 목표다. 기능 포팅은 아래 완료·미완료와 검증 범위로 판단하며, 이번 이야기 변경이나 테스트 통과를 전체 포팅 완료로 환산하지 않는다. 위의 단서 17종은 기존 메타 단서이며, 시간 이야기의 필드 기록물 23개와 별개다.
