# 게임 품질 개선 · 2026-09-13

[v352 검토](game-quality-audit.md)의 후속 구현 기록이다. 사용자는 짧은 반복을 우선 개선하고, 본편 20개를 유지하면서 지역 조사를 병렬화하고 대체 보고를 허용하도록 승인했다. 아래는 해결한 부분과 아직 검증하지 못한 부분을 구분한다.

## 실제로 바뀐 플레이

| 영역 | 변경 |
| --- | --- |
| 첫 전투 | Lv1에 2획 도형 두 칸을 사용한다. 인간은 방어·받아넘기기, 나방은 조준·몸빼기, 화이트팡은 잔상·겹수, 슬라임은 독·번지기, 스민투스는 설치·끌기를 처음 장착한다. |
| 준비와 한 방 | 방어 유지 후 남은 방어를 소모하는 반격, 느린 조준, 약화 증폭, 폭발 설치의 보상을 조정했다. 느린 공격은 빈 칸을 미리 겨눌 수 있고, 적이 그 칸을 떠나면 빗나간다. 이동이나 체력 피해에 따른 집중 취소는 유지한다. |
| 적의 압박과 빈틈 | 몸을 맞히지 못한 느린 공격은 2턴, 넓은 보통 공격은 1턴의 빈틈을 남긴다. 피해 보너스와 의도 표시가 같은 기간 유지된다. 빠른 좁은 공격과 실제로 명중한 공격에는 추가 빈틈이 없다. |
| 던전 | 가능한 권역에서는 같은 적 두 마리 대신 이동·사거리·시전·상태가 다른 원본 마물을 섞는다. 보관함은 물·붕대·연막·전격 등 사용 가능한 준비물이 다르게 나온다. 기존에 생성된 방과 재고는 보존한다. |
| 채집과 정착 | 군락의 실제 잔량을 소모하면서 생활 숙련의 품질·산출·성장이 적용된다. 집을 지을 때 원석과 생활 광석을 섞어 쓸 수 있다. |
| 생산의 소비처 | 마을에 접힌 납품 의뢰 목록을 복구했다. 가공품을 담당자에게 실제로 전달해 생활 성장과 시간의 조각으로 연결한다. 부족한 재료, 원거리 거래, 중복 보상을 차단한다. |
| 본편 조사 | 첫 입장 선택을 지역 조사 전에 배치하고 준비 보상을 달리했다. 던·티프레·에니참 권역의 조사 순서를 바꿀 수 있고 현장 기록이나 다른 담당자에게 보고한다. 일반 인사로 핵심 증언이 채워지지 않는다. |
| 정보 단절 | 필수 기록을 파괴해도 잔해에서 확인하고, 일반 필수 NPC가 사망하면 실제 유품을 찾아 이어간다. 최종 시나리오는 여전히 직접 수락해야 보스전이 열린다. |
| 던·티프레 | 최신 사용자 결정에 따라 사망하지 않는다. 쓰러지면 합류를 풀고 거점으로 귀환해 회복한다. 자동 재영입하지 않으며, 최종전은 실제 동행해 현장에 있는 사람만 참여한 것으로 기록한다. 부재는 진 엔딩을 막지 않는다. |

기존 저장은 장착·강화·인챈트·재사용 시간을 보존한다. 새 초반 학습 카드 지급은 한 번만 적용하며, 이미 지급받은 카드를 강화 재료로 쓴 뒤 변신하거나 불러와도 다시 주지 않는다. 과거 저장의 쓰러진 던·티프레는 회복 상태로 이전한다.

## 확인한 것

- 실제 데이터와 공개 필드 입력으로 준비 기술의 비용·쿨타임·효과·실패 조건을 검사했다.
- 정지 표적 비교: 기본 공격 2회 14, 방어 후 반격 18, 느린 조준 21, 겹수 후 잔상 26. 모두 같은 위험이나 턴 수의 공격이 아니다. 방어가 깨지거나 표적이 움직이면 준비가 손실된다.
- 정상 시작 자원으로 일루네온 광장부터 14칸 이동해 다섯 종족의 첫 마물을 상대했다. 인간 9행동, 나방 5행동, 화이트팡 7행동, 슬라임 20행동, 스민투스 5행동으로 격파했다. 성장·장거리 진행을 포함한 게임 전체 클리어 검사는 아니다. [초반 전투의 조건과 관측](starter-combat-playtest.md).
- 이야기 6경로는 서로 다른 지역 순서, 두 불완전 결말, 카오스 동행·독행·초기 이탈·일반 NPC 사망을 검사했다. 레벨·준비물을 통제하고 장거리 이동을 생략한 실행이다. [상세 기록](time-story-playtest.md).
- 빈틈은 저장 복원, 기존 취약, 수면, 벽에 잘린 광역 공격을 함께 검사했다. 긴 기존 취약을 줄이지 않는다.
- 채집·가공·납품·혼합 건설은 실재 재고 감소와 보상, 저장 복원, 채집지별 재생까지 검사했다.

배포 전 데이터 69파일 검증과 빌드가 통과했다. 배포 작업의 회귀 스크립트 22종을 실행했고, 저장 이행 표시가 누락된 성장 테스트 준비값을 수정한 뒤 해당 검사도 통과했다. 390×844 화면에서는 저장 이어하기, Lv1 두 기술의 장착, 필드에서 마을 진입, 접힌 납품 목록·수락·페이지 이동을 확인했다. 마을의 예전 별도 동료 목록은 숨기고 실제 필드 NPC와의 교류를 사용한다.

## 남은 반복과 한계

**전체 게임의 반복감이 해결됐다고 판정하지 않는다.** 가까운 안전 칸으로만 피하는 정책은 빠른 첫 마물과도 오래 교착했다. 거리 확보·방어 교환·설치 유도·예측 조준을 쓰면 해결되지만, 플레이어가 이 차이를 자연스럽게 배우는지는 실제 플레이 의견이 필요하다.

느린 적의 시전과 빈틈 동안 마나가 회복되므로, 단일 적을 상대로 회피 후 저비용 마법을 반복하는 방식은 여전히 가능하다. 혼합 편성의 효과를 다양한 실제 장비·직업으로 충분히 측정하지 않았다.

지역 조사의 순서와 왕복은 줄였지만 기록을 읽는 행동 자체는 남아 있다. 카오스 재도전만의 완전히 별도인 조사 시나리오, 시간 보스의 고유 되감기 기믹, 중후반 생산 구조 차이까지 완성한 것은 아니다. 사냥·생산·교류 중심의 세 성장 경로로 자원 확보와 이동을 포함해 중반 난관까지 비교하는 검증도 남는다.
