# 권역·채집·여정 — v351

2026-09-12. 기존 필드 포팅 위에 추가한 생활·탐험 에피소드다. 전체 포팅 완료를 뜻하지 않는다.

## 플레이 흐름

일루네온 광장의 니아 이유르에게 「돌아올 곳」을 받는다. 공동 마당의 집에서 기술을 준비하고, 하코의 연습·에코의 가공을 거쳐 올뤼의 지도 만들기를 돕는다. 수첩에는 현재 여정과 받은 부탁, 실제로 확인한 NPC 위치만 표시한다.

- 주요 여정 16단계: 집 → 기술 → 섬유 → 가공과 사용 → 마로에게 전달 → 숲의 못 → 세계수 → 협곡 → 바람길 → 숯 → 전등 → 휴식 지점 → 조립 → 일루네온 길 확인 → 다음 여행의 짐 → 귀환.
- 별도 부탁 4개: 임페리시아·에코·로크·리제.
- 낮에는 이유르·하코가 광장, 에코가 시장, 올뤼·미유가 시계탑에서 안내한다. 이동 시간과 야간 귀가, 기존 일정 사건을 유지한다.
- NPC 부재·사망·이동·거리·시야·수면·관계를 검사한다. 대리 NPC나 무조건 재생성으로 진행을 보장하지 않는다. 납품은 실제 재고를 NPC에게 옮기며 보상은 한 번만 받는다.
- 장편 중심 질문에 답이 없는 동안 생활·탐험 방향으로 완결되는 지역 에피소드를 선택했다. 세계의 큰 사건이나 인물의 과거를 새 정사로 확정하지 않는다.

## 지형과 재고

25개 권역에 광장·숲·능선·해안·협곡·평원·고산·회랑·동굴·공업 지형을 연결했다. 협곡과 해안은 가로로 길고, 고산은 세로로 길며, 회랑과 공업 지형은 정방형 중심이다. 바위 권역에는 이동 가능한 바위가 세 개까지 배치된다. 출구 방향과 원본 노드 간 거리, 중간 길은 유지한다.

반복 채집지는 각각 독립된 재고를 가진 최대 2×2 군락이다. 좁으면 3칸 또는 2칸으로 줄인다. 새 군락의 한 칸 재고는 2개이며 한 번에 1개씩 채집한다. 남은 수량과 게이지를 격자에 겹쳐 표시해 화면 높이를 바꾸지 않는다. 기존 저장의 남은 재고는 보존한다. 재생 가능한 군락도 재방문만으로 채워지지 않는다.

개발용 희귀 자원 위치: 샘의 씨앗은 n-lar-inner-pool, n-limun-ruins 두 장소에 한 개씩만 생성하고 재생하지 않는다. 밭이나 빈 흙에 심으면 실제 물 공급원이 된다.

## 가공과 사용

작업대·화로·장인 옆에서 가방의 가공 메뉴를 연다. 완성품을 손에 고르고 대상을 선택하면 해당 동작을 그 자리에서 안내한다.

| 완성품 | 재료 | 사용 |
| --- | --- | --- |
| 연막 포자 ×2 | 버섯 1, 섬유 1 | 시야를 가리는 연기 |
| 수액 연고 | 섬유 2, 물 1 | 체력 12 및 3턴 재생 |
| 전하 소금 ×2 | 전하석 1, 철광 1 | 전격, 젖은 대상과 상호작용 |
| 보강 붕대 | 섬유 1, 철광 1 | 방어 12, 2턴 유지 |

재료 소모·대상 상태 변화·물 공급원 생성은 기존 공통 상호작용 라우터로 처리한다. 재료가 모자라거나 대상에 쓸 수 없으면 재고가 사라지지 않는다. 기존 전투 소비품 전체의 상태 해제·마나 회복 포팅은 별도 미완료 항목이다.

## 문장과 저장

NPC 57명의 인사와 인물별 대화 주제 3개, 기존 사건 180개의 본문·선택지·결과, 일정 사건 8개와 보스·아크 대사를 다시 작성했다. 사건 변형의 조건·효과·보상은 유지한다. 이번 인물 해석은 저장소의 캐릭터 설정집을 기준으로 했고 Yeoun 원문을 확인했다고 간주하지 않는다. 모든 사건을 실제 플레이로 읽어 본 것은 아니므로 인물 해석과 전체 흐름의 추가 감수는 남긴다.

필드 레이아웃 v4와 군락·지역 소품의 일회 이전 플래그를 사용한다. 기존 작물 생산, 물건 이동·소지, NPC 생사, 채집한 재고를 보존한다. 퀘스트 수락·완료·행동 기록도 저장된다.
