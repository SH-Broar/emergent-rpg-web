# COLOR 공통 조작

2026-09-12. 불·물·전기·철·흙·바람·빛·어둠의 두 방향, 총 16개다. 새 조작은 `InteractionAction`으로 조합해 기존 물성·상태·이동·목격 판정에 전달한다. 퀘스트 ID나 특정 NPC에 맞춘 정답 판정은 없다.

| COLOR | 동작 | 마나 | 실제로 바뀌고 소비되는 상태 |
| --- | --- | ---: | --- |
| 불 | 가열 / 냉각 | 1 / 1 | 열·연소. 가연물 발화, 열과 불길 감소, 화상 감소 |
| 물 | 적심 / 회수 | 1 / 1 | 적심은 물 1개 소모, 회수는 수분 3을 물 1개로 회수. 열을 흡수하고 전도율에 영향 |
| 전기 | 방전 / 절연 | 2 / 1 | 전격 피해는 젖음·전도율·절연에 반응. 절연은 피해 배율의 실제 제수이며 마비·경련도 감소 |
| 철 | 경화 / 연화 | 1 / 1 | 물리 저항의 경도 증감. 생명체 경화에는 짧은 방어도 추가 |
| 흙 | 다짐 / 풀기 | 2 / 1 | 빈 바닥 다짐은 철광 1개 소모, 기존 바닥 개체의 성질을 바꿔 실제 통행을 막음. 생명체에는 이동 구속/해제 |
| 바람 | 밀기 / 당기기 | 1 / 1 | 실물 한 칸 이동. 질량·벽·점유 검사, 대각선 이동 없음. 밀기는 연기도 흩음 |
| 빛 | 비춤 / 각성 | 1 / 1 | 빛·주의가 필요한 생산 돌봄. 각성은 잠·졸음·혼란 감소 |
| 어둠 | 가림 / 진정 | 1 / 2 | 장막은 기존 연기 시야층을 사용. 진정은 졸음·수면과 주의 저하에 연결 |

조작 하나는 30초를 진행하며 기존 두 턴당 마나 1 회복 주기를 쓴다. 거리와 시야, 행동 제한, 실제 재료와 마나를 함께 검사한다. 필요한 재료가 없으면 마나만 먼저 빠지지 않는다. 거절된 빈 땅 조율은 새 월드 개체도 남기지 않는다. 강화 수치에는 상한이 있으며, 바람으로 옮길 수 있는 질량과 전격의 위력에는 해당 COLOR 값이 반영된다. 모든 동작이 모든 대상에서 유효한 것은 아니다. 현재 성질로 변화가 생기지 않으면 실행하지 않는다.

흙 풀기는 실제 물체의 `solid`를 낮추며 지도 타일의 고정 벽 자체를 삭제하지 않는다. 빛은 현재 생산 돌봄에서 소비하며, 지도 전체의 밤낮 조명 엔진을 새로 구현한 것은 아니다. 장막은 실제 시야를 차단하지만, 새 어둠 전용 퍼즐 플래그는 만들지 않는다. 보스·아크의 환경 피해 면역은 별도의 확정 전투 규칙을 따른다.

바람으로 옮긴 몸이나 무게 있는 물건도 기존 설치물의 실제 칸에 닿으면 발동시킨다. 보행·이동기 경유 칸·시간 경과도 같은 접촉 판정을 쓴다. 직접 전격은 기존 유령의 원거리 면역을 따르며, 최대 HP가 큰 마물의 남은 HP가 1이어도 정상적으로 마무리할 수 있다.

목격 사실은 대상의 당시 분류를 보존한다. 사람에게 강제로 건 수면·구속·이동·상해는 목격자의 위해 회피 성향에 따라 신뢰에 반영된다. 마물과의 전투, 자기 행동, 남의 수면 해제·방어·연고 치유를 같은 위해로 판단하지 않는다.

기록 23개는 가까이에서 바로 읽을 수 있다. 물을 먼저 쓰라는 조건은 제거했다. 기록물도 다른 물건처럼 운반·가림·재질 변화·파괴 규칙에 참여하지만, 새 조작을 하나씩 강제로 시험하는 문으로 쓰지 않는다.

검증: `node scripts/test-field-color-actions.mjs`의 11개 그룹에서 모든 16개 동작을 실제 공통 엔진으로 실행했다. 공개 입력인 test-field-color-input은 20개 그룹에서 실제 비용·시간·동작·함정·사회 판단을 검증했다. 390×844에서 절연 드래그 실행과 조율 패널 열고 닫을 때의 격자 크기 유지도 확인했다. 통제된 검사와 짧은 화면 검수이며, 전체 여행의 재미는 별도 통합 플레이에서 확인한다.
