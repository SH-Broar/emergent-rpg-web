# 격자 생활 시뮬레이션

## 공간과 조작

- 275개 기존 장소의 좌표와 연결 관계를 보존한다. 단순한 장소는 6×6, 전투 구역은 8×7~9×8, 마을은 10×10~12×10이다. 화면은 해당 구역 안에서만 이동한다.
- 긴 연결에는 원래 간격에 비례한 41개의 6×6 중간 길을 추가한다. 경로 조건은 그대로 적용되며, 길을 걷는 도중에는 목적지를 방문 처리하지 않는다.
- 지도는 현재 구역 전체와 출구, 275개 장소의 세계 지도를 제공한다. 권역·장소를 선택해 자세히 볼 수 있으며, 전체 보기에도 원래 거리 비율을 유지한다.
- 숲·도시·해안·화산·동굴·초원 지형과 소품을 구분한다. 생성과 저장 이전 시 모든 출구와 물건에 접근 가능한지 검사한다. 혼잡한 이전 저장은 같은 칸에 물건을 함께 놓아 재고·작물·진행을 보존한다.
- 빈 칸을 누르면 상하좌우 경로로 이동한다. 한 칸은 정확히 30초다. 방향 입력은 한 칸 이동하거나, 막는 대상과 상호작용한다.
- ●는 대화·수확·채집·시설 진입, ╱는 힘 가하기·방어, ╲는 심기·돌보기다. ∧ ∨는 운반, ⊂ ⊃는 재고 이전이다. 오른쪽 실행 버튼은 없고 대상 곁의 힌트와 도형 모음은 연습선만 켠다.
- 이전 화살표·삼각형 숙련도를 새 입력으로 이관한다. 카탈로그에 경로·허용 오차·물질 효과를 추가하며, 복잡한 ☆ 문양에는 정확도와 실제 드로잉을 요구한다.
- 하단 조작부는 고정 높이다. 같은 칸의 대상·재고·대사·성장·메뉴는 격자를 밀어내지 않는 겹침 창이다. 시간은 지도 안에서 확인하며 자동 진행 타이머를 상시 표시하지 않는다.
- NPC는 한 번에 한 대사를 말한다. 점 터치로 대화를 시작하고, 일·지역·근황 주제로 이어간다.
- 인물을 누르면 현재 위치를 따라 선택한다. 빈 칸은 이동 목적지이며 이동 중 경로를 표시한다. 맵 경계와 중간 길에서 진행 방향을 유지한다.
- ϟ를 그린 뒤 표시된 착지 칸을 누르면 이동기를 쓴다. 마나는 3칸으로 표시하며 두 턴마다 1 회복한다.

## 전투와 생활

- 필드 마물의 예고한 공격을 피하고, 물건을 옮기거나 실제 식량으로 유인할 수 있다. 던전은 별도 입구와 여러 층, 기존 엘리트와 보스를 갖는다.
- 공통 영향(운반·이동·재고 이전·힘·재료·신호)은 같은 세계 엔티티에 적용한다. 물질 반응·소유·노동·목격·관계 기록을 공유한다.
- 용기의 실제 물이 파괴 시 퍼지고, 젖은 바닥이 이후 방문자에게 영향을 준다. 연기와 벽은 시야를 가린다.
- 장비 컬러와 도형 숙련은 실제 힘과 방어량에 적용된다. 피해·방어·회복·빗나감은 발생 칸에 표시한다.
- 원본 공격 순서·타일 배율·상태 부여를 사용한다. 엘리트와 보스는 광역 예고, 보스는 체력 단계와 조우 대사를 갖는다. 32종 상태의 설명은 상태 표시를 눌러 확인한다.
- 현장 시설은 상점·공방·마을·활동·사건 화면과 연결된다. 여덟 지역 생활 활동을 현장에서 실행하며 생산은 떠나 있어도 진행된다.
- 생활 2의 자동 돌봄, 3의 생산 방식 선택, 5의 산출 보너스를 연결한다. 성장 창에서 다음 생산 방식을 고른다.

## 시뮬레이션 경계

- 입력 없이 5초가 지나면 30초를 진행한다. 대화·메뉴·지도·튜토리얼·드로잉·경로 이동·브라우저 숨김 중에는 자동 시계가 멈춘다. 밀린 턴을 몰아서 실행하지 않는다.
- 상세 물질 반응과 NPC/마물 판단·경로 탐색은 화면과 한 칸 여유 범위에서 수행한다.
- 화면 밖은 매 게임 5분 또는 다시 보일 때 산술 정산한다. 생산·재생·열/연기·욕구·보유 식량·인접 작업을 정산하며, 지난 이동·공격·불 확산을 모두 재현하지 않는다.
- 기존 카드 전투의 모든 카드·유물·동료 전투 효과를 새 도형 전투로 이식한 상태는 아니다. 기존 화면과 보관 데이터는 유지한다.
