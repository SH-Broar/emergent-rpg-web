# 격자 생활 시뮬레이션

## 이번 전환

- 점과 선으로 된 월드맵을 제거한다. 기존 장소는 연결된 격자 구역으로 바꾸고, 길 끝을 직접 걸어서 오간다.
- 빈 칸을 누르면 상하좌우 경로로 이동한다. 한 칸은 정확히 30초이며, 막힌 경로에는 시간을 쓰지 않는다.
- 대상이 있는 칸을 누르면 접근해 그 대상을 바라본다. 조작부는 하단에 모은다.
- ↑ ↓ ← → △ ▽ ○를 직접 그리거나 같은 도형을 누른다. 플레이 화면에는 도형에 특정 행동 이름을 붙이지 않는다.
- 도형은 공통 영향(운반·이동·재고 이전·힘·재료·신호)으로 변환된다. 대상의 성질이 결과를 결정한다.
- 건물, NPC, 풀숲, 운반 가능한 물건, 재배지, 마물은 같은 세계 엔티티다. 소유·노동·목격·관계 기록도 공유한다.
- 필드에서는 마물을 피하거나 물건과 지형을 활용한다. 던전은 별도의 입구와 여러 층, 엘리트와 보스가 있는 지속 구역이다.
- NPC는 실제 대사를 말한다. 한 번에 한 대사만 표시하고 관계와 목격한 사건을 반영한다.
- 기존 종족·세계관·NPC·엘리트·보스 정의를 보존한다. 기존 세이브는 장소와 자원을 유지한 채 격자 위치를 배정한다.

## 검증 기준

도형 인식의 크기·시작점 변화 및 오입력, 대각선 금지/장애물 경로, 30초 누적, 운반 후 재배치와 재고 보존, 다른 장소에서 진행되는 생산, NPC 이동/대화/목격, 필드 교전과 던전 왕복, 저장 복원, 모바일 포인터 입력을 확인한다. 브라우저 입력은 Pointer Events와 pointer capture, touch-action으로 구현하고 터치 취소 시 행동을 실행하지 않는다.

## 구현 경계

- `field-simulation`은 입력을 공통 원시 효과로 번역하고 30초 단위로 세계를 진행한다. 물질 반응과 목격 기록은 `world/engine`이 처리한다.
- 용기의 실제 물 재고가 파괴 때 퍼진다. 파괴한 주체를 구분하지 않는다. 바닥의 수분은 나중에 같은 칸에 들어온 대상에도 전달된다.
- 연기와 벽은 시야를 가린다. 마물은 눈에 보이는 식량을 소비하며, 공격할 칸을 먼저 고정하므로 이동·물건 배치로 결과를 바꿀 수 있다.
- 구역은 첫 방문 때 생성되며, 물건 위치·재고·밭·던전 진행을 저장한다. 생성된 구역의 NPC와 생산은 플레이어가 떠나도 진행된다.
- 이전 카드 전투 화면과 데이터는 호환을 위해 남아 있지만 새 여정과 이어하기는 격자 필드로 진입한다.

## 검증 기록 · 2026-09-10

- `npm run build` 통과.
- `node scripts/test-field-simulation.mjs`: 13개 통합 시나리오 통과. 모든 기존 장소의 출구까지 실제 경로를 검사한다.
- 기존 `test-world-interactions`, `test-life-production`, `test-tactical-combat`: 합계 37개 시나리오 통과.
- 모바일 크기 브라우저에서 포인터 드래그로 물통 운반·재배치를 확인했다. 실제 Android 기기의 터치 입력은 아직 검증하지 않았다.
- `npm run validate`: 기존 이벤트 데이터의 이름 누락·참조 오류 180개가 남아 있다. 해당 데이터와 검증기는 이번 변경 전 HEAD와 동일하며, 이 결과를 새 필드 테스트 통과로 대체하지 않는다.
