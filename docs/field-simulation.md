# 격자 생활 시뮬레이션

## 이번 전환

- 플레이 공간은 각각 고정된 15×13 격자 구역이다. 화면은 구역 안에서만 이동하며, 출구를 걸어 통과하면 연결된 별도 구역으로 전환한다. 연속 오픈월드가 아니다.
- 하단 지도는 현재 구역 전체와 출구, 별도의 세계 권역 지도를 제공한다. 세계 지도에서 권역을 선택하면 연결된 권역과 이미 방문한 장소를 볼 수 있다.
- 빈 칸을 누르면 상하좌우 경로로 이동한다. 한 칸은 정확히 30초이며, 막힌 경로에는 시간을 쓰지 않는다.
- 대상이 있는 칸을 누르면 접근해 그 대상을 바라본다. 조작부는 하단에 모은다.
- ↑ ↓ ← →는 선택 대상과 무관하게 해당 방향 한 칸을 이동한다. 이동할 수 없는 칸의 NPC·마물·물건에는 공통 속성에 따른 상호작용을 시도한다. 실패는 시간을 소비하지 않는다.
- △ ▽ ○ 및 운반·재고 이전용 ∧ ∨ ⊂ ⊃를 직접 그리거나 도형 모음에서 고른다. 플레이 화면에는 도형에 특정 행동 이름을 붙이지 않는다. 기존 화살표 숙련은 새 운반·이전 도형으로 한 번 이관한다.
- `gesture-catalog.ts`에 문양의 경로·허용 오차·공통 물질 효과를 등록한다. 기본 도형은 작은 입력과 불균등한 삼각형을 허용하며, ☆ 같은 복잡한 문양은 더 엄격한 정확도와 실제 드로잉을 요구한다. ☆는 MP 3을 쓰는 전하 영향의 첫 예시다.
- 도형은 공통 영향(운반·이동·재고 이전·힘·재료·신호)으로 변환된다. 대상의 성질이 결과를 결정한다.
- 건물, NPC, 풀숲, 운반 가능한 물건, 재배지, 마물은 같은 세계 엔티티다. 소유·노동·목격·관계 기록도 공유한다.
- 필드에서는 마물을 피하거나 물건과 지형을 활용한다. 던전은 별도의 입구와 여러 층, 엘리트와 보스가 있는 지속 구역이다.
- NPC는 실제 대사를 말한다. 한 번에 한 대사만 표시하고 관계와 목격한 사건을 반영한다.
- 기존 종족·세계관·NPC·엘리트·보스 정의를 보존한다. 기존 세이브는 장소와 자원을 유지한 채 격자 위치를 배정한다.

## 검증 기준

도형 인식의 크기·시작점 변화 및 오입력, 대각선 금지/장애물 경로, 30초 누적, 운반 후 재배치와 재고 보존, 다른 장소에서 진행되는 생산, NPC 이동/대화/목격, 필드 교전과 던전 왕복, 저장 복원, 모바일 포인터 입력을 확인한다. 브라우저 입력은 Pointer Events와 pointer capture, touch-action으로 구현하고 터치 취소 시 행동을 실행하지 않는다.

## 구현 경계

- `field-simulation`은 입력을 공통 원시 효과로 번역하고 30초 단위로 세계를 진행한다. 물질 반응과 목격 기록은 `world/engine`이 처리한다.
- 용기의 실제 물 재고가 파괴 때 퍼진다. 파괴한 주체를 구분하지 않는다. 바닥의 수분은 나중에 같은 칸에 들어온 대상에도 전달된다.
- 연기와 벽은 시야를 가린다. 마물은 눈에 보이는 식량을 소비하며, 공격할 칸을 먼저 고정하므로 이동·물건 배치로 결과를 바꿀 수 있다.
- 구역은 첫 방문 때 생성되며, 물건 위치·재고·밭·던전 진행을 저장한다.
- 입력 없이 5초가 지나면 30초를 진행한다. 대화·도형 모음·소지품·지도·튜토리얼·설정·드로잉·경로 이동·브라우저 숨김 중에는 자동 시계가 멈춘다. 다시 보였을 때 밀린 턴을 몰아서 실행하지 않는다.
- 상세 물질 반응과 NPC/마물의 판단·경로 탐색은 화면과 한 칸 여유 범위에서 수행한다. NPC 후보 평가도 해당 구역만 조회하며, 사회적 해석은 실제 목격자만 처리한다.
- 화면 밖에서는 매 게임 5분 또는 다시 보일 때 경과 시간을 산술 정산한다. 작물 완성·재고 재생·열/연기 감소·NPC 욕구와 보유 식량 소비·인접 작업을 정산하지만, 지난 이동·공격·불의 확산을 모두 재현하지는 않는다. 이는 의도적인 근사이며 상세 시뮬레이션과 결과가 항상 동일하지 않다.
- 이전 카드 전투 화면과 데이터는 호환을 위해 남아 있지만 새 여정과 이어하기는 격자 필드로 진입한다.

## 검증 기록 · 2026-09-10

- `npm run build` 통과.
- `node scripts/test-field-simulation.mjs`: 16개 통합 시나리오 통과. 방향 이동/막힘 상호작용, 문양 정확도/마나 비용, 모든 기존 장소의 출구, 화면 밖 정산을 포함한다.
- `node scripts/test-gesture-input.mjs`: 36개 크기별 문양, 24개 불균등 삼각형, 사용자 정의 문양, 작은 선/떨림과 자동 시계 4개 시나리오 통과.
- 전체 장소를 미리 생성한 2,956개 엔티티에서 상세 대상은 17개. 로컬 Node/Pinia 스트레스 검사에서 10턴 합계 약 1.7초(일반 턴 약 40ms, NPC 판단 턴 약 400ms). 실제 모바일 기기의 성능 수치가 아니다.
- 기존 `test-world-interactions`, `test-life-production`, `test-tactical-combat`: 합계 37개 시나리오 통과.
- `verify-region-world`: 사회적 목격·관계·증언 중복 방지 회귀 검사 통과.
- 390×844 브라우저에서 세계/구역 지도, 방향 버튼, 10px 실제 포인터 드래그 이동, 5초 자동 진행과 지도 열림 중 정지, 삼각형 연습선을 확인했다. 콘솔 오류 없음.
- 모바일 크기 브라우저에서 포인터 드래그로 물통 운반·재배치를 확인했다. 실제 Android 기기의 터치 입력은 아직 검증하지 않았다.
- `npm run validate`: 기존 이벤트 데이터의 이름 누락·참조 오류 180개가 남아 있다. 해당 데이터와 검증기는 이번 변경 전 HEAD와 동일하며, 이 결과를 새 필드 테스트 통과로 대체하지 않는다.
