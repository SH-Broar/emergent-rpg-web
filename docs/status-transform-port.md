# 상태 연출과 종족 변신 포팅

## 이번 변경
- 필드 상태이상 21종을 수면·구속·독·화상 등의 가장자리 무늬와 색으로 구별한다.
- 상태가 사라지거나 플레이어가 사망하면 효과를 제거한다. 상태 중첩이 늘어도 화면이 더 어두워지지 않는다.
- 덮개 하나와 무늬 최대 두 개만 표시한다. 효과는 맵 내부에 고정하고 입력을 받지 않으며, 격자 크기·하단 조작 패널·게임 상태를 변경하지 않는다.
- 삼킴의 약한 암전과 기존 저장의 변신 표시는 렌더링 규칙만 준비했다. 신규 필드 전투의 삼킴·변신 발동 및 해제는 아직 포팅하지 않았다.
- 브라우저 연결이 없어 모바일 화면의 실제 가독성 검수는 남아 있다.

## 원본에서 확인한 변신 규칙
- 타마모의 원본 intent는 수화를 부여한 뒤 2단계에서 수화 조건의 change:race-form-fox를 실행한다. 현재 필드는 gridBehavior를 사용하므로 이 조건부 변신이 실행되지 않는다.
- combat.ts의 applyTransformation은 종족을 여우로 바꾸고 종족 기본 덱으로 교체한다. 원래 종족·덱·수집 카드·덱 크기는 run.transform에 보관한다.
- 변신은 전투 후에도 남는다. 해제 누적값 5를 본모습 카드가 사용당 2씩 줄이며, 정화는 즉시 원상 복구한다.
- 원본 구현은 HP와 기본 능력치를 덮어쓰지 않는다. 여우 데이터의 능력치는 변신에 사용하지 않는 임시 값이라고 명시되어 있다.
- 여우의 체형, 장착 기술·강화·인챈트의 변신 중 처리, 해제 경로는 사용자 기획 답변을 받은 뒤 확정한다. 기존 투자는 해제 시 원래 사본에 복구되어야 한다.
- 포팅 시 기술 슬롯뿐 아니라 재사용 대기·예약 시전·종족 외형·월드의 플레이어 종족 정보도 함께 처리해야 한다.

## 원본에서 확인한 삼킴 규칙
- devour는 grapple의 누적 게이지와 기본 피해·증가량을 가진다. 시간이 흐를수록 피해가 커지고, 강한 발버둥의 색 순서 입력으로 탈출한다.
- 현재 필드에는 해당 게이지·누적 피해·탈출 입력이 없다. 암전만으로 이 기믹을 완료 처리하지 않는다.

## 이번 버전 범위
동료 영입·동행·동료 카드·쿨다운·생존은 포팅하지 않는다. 기존 자료는 보존하고, NPC와의 교류는 별도 방식으로 설계한다.

## 검증
- node scripts/test-status-feedback.mjs: 현재 필드 디버프 포함, Vue SSR 출력, 상태 비변경, 해제, 중첩 상한, 변신 표시와 사망의 표시 수명.
- npm run build: TypeScript와 배포 빌드.
- 이 검증은 변신 및 삼킴의 전투 포팅 완료나 실제 터치 화면 검수를 뜻하지 않는다.
