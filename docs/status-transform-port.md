# 상태 연출과 종족 변신 포팅

## 확정한 세계관과 규칙
- 타마모의 변신 결과는 사람 체형의 수행 여우. 여우 귀와 꼬리 둘을 갖는다.
- 원래 기술은 봉인한다. 기존 카드의 사본 ID·강화·인챈트·각성·기술 배치를 보관한다.
- 변신을 풀 수 있는 NPC를 실제로 찾아야 한다. 현재는 기존 설정에서 정령과 마법에 정통한 구미호 카시스에게 해당 능력을 부여했다.
- 동료 영입·동행·동료 카드·쿨다운·생존은 이번 버전에서 포팅하지 않는다.

## 타마모
- 기존 수화 유도 → 후반 종족 변신의 연결을 유지했다.
- 1단계 꼬리 후리기, 2단계 홀림불에 수화 3. 2단계의 세 번째 공격은 ‘수행의 낙인’으로, 두 턴 동안 범위를 예고한다.
- 비수화 대상이 낙인을 맞으면 수화 3을 부여하며 그 타격에서 변신까지 연속 판정하지 않는다. 이미 수화 또는 심수화 상태인 생존 대상은 변신 확률을 판정한다. 이탈하면 빗나가며, 이미 변신 중인 대상의 원본을 덮어쓰지 않는다.
- 초기 밸런스: 레벨 1에서 80%, 레벨당 4%p 감소, 최소 10%. 레벨 10은 44%, 레벨 20 이상은 10%. 저장된 런 난수를 쓰므로 같은 예약 공격을 재접속해 다시 추첨하지 않는다.
- 일반 처치 XP 1, 엘리트 XP 3을 기존 성장 함수에 연결했다. 처치 완료 표식으로 중복 지급을 막고 분열체는 제외한다. 보스·아크는 기존 XP 보상을 사용한다.

## 강제 패배
- 수행 여우 상태에서 타마모를 만나면 전투 없이 기절한다. 일반 기절과 같은 시간·귀가 규칙을 쓰며 목숨은 무한이다.
- 조우·진행 중인 전투·변신 직후·즉발/예약 기술보다 먼저 판정한다. 타마모 처치나 승리 보상은 발생하지 않으며 변신과 수련은 유지한다.
- 자세한 시간과 거점 규칙: [기절과 거점](bases-and-recovery.md).

## 변신 중
| 도형 | 기술 | 마나 | 재사용 |
| --- | --- | ---: | ---: |
| ⌞ | 작은 여우불 | 1 | 3턴 |
| ⌝ | 수행자의 장막 | 1 | 4턴 |
| △ | 두 꼬리 쓸기 | 2 | 4턴 |
| ▽ | 물러서는 걸음 | 1 | 3턴 |
| ○ | 흐린 부적 | 2 | 5턴 |

- 실제 종족 ID와 월드 인물의 종족, 외형, 노동 능력과 단단함이 바뀐다. HP·마나·컬러·장비·직업·관계는 유지한다.
- 기술은 기존 도형·마나·쿨다운·공통 속성 라우터로 실행한다. 이동·생활·대화 같은 기본 조작은 계속 가능하다.
- 변신 순간 시전 중이던 원래 기술과 일회성 준비 효과는 중단한다. 이미 지불한 마나는 반환하지 않는다. 원래 기술의 절대 재사용 시각은 보존해 시간이 계속 흐른다.
- 원래 기술은 봉인하지만 여우 기술은 공방에서 위력·효율·순환·사거리·각성·인챈트를 성장시킨다. 공격 기술은 각성 후 30강까지, 나머지는 10강까지 기존 규칙을 사용한다. 일반 카드 보상은 강화 재료로 쓰거나 해제 후 원래 수집 카드와 합친다.
- 전투 종료·휴식·시간 경과·기절은 종족 변신을 해제하지 않는다. 본모습 카드와 정화 아이템도 해제 경로가 아니다. 효과가 없는 본명의 거울은 소모하지 않는다.
- 기존 변신 저장도 수행 여우 기술로 이전하며 원본 보관 카드를 유지한다.

## NPC와 해제
- 카시스의 실제 월드 엔티티에 restore:race-form-fox 능력 태그를 부여한다. 마을 서비스 메뉴나 NPC를 대신하는 자동 해제 지점을 만들지 않는다.
- 가까이서 말을 건 뒤 ‘원래 모습으로’를 선택한다. 실행 시 생존·현 위치·인접 거리·시야·행동 가능 상태·관계를 다시 확인한다.
- NPC가 사망·부재·이동·수면 상태가 되면 열어 둔 대화 선택으로도 해제되지 않는다. 해당 인물을 부활시키거나 옛 위치로 되돌리지 않는다.
- 카요·발렌시아와 마법을 아는 주민은 카시스가 모스 대장간에 들르곤 한다는 단서를 준다. 현재 위치를 원격으로 보장하지 않는다.
- 원래 기술의 투자와 배치를 복구하며 여우 기술은 별도 수련 기록에 보관한다. 사본 ID·강화·각성·인챈트·장착·절대 쿨다운을 재변신 때 그대로 복구한다. 변신 중 획득한 일반 카드·경험치·물품은 보존한다.

## 화면 효과
- 현재 필드 디버프 21종에 맵 가장자리 색과 무늬를 표시한다. 덮개 하나와 무늬 최대 두 개, 상태 중첩에 따른 암전 누적 없음.
- 두 꼬리 인간형 외형과 짧은 변신 상태 표시를 추가했다. 격자 크기와 하단 조작 영역은 고정한다.
- 삼킴의 약한 암전 규칙은 준비했지만, 누적 피해·탈출 게이지 및 탈출 입력은 아직 미포팅이다.
