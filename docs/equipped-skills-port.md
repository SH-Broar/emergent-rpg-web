# 기술 장착과 성장 포팅

## 확정 방향
손패 대신 8개 도형에 기술을 장착한다. 남는 일반 카드는 종류에 관계없이 강화 재료로 쓴다. 획수는 난이도 등급이며 원은 4획이다. 같은 마법도 더 쉬운 도형으로 쓰는 카드, 별로만 쓰는 카드가 존재한다. 세계 시간은 계속 흐르지만 여정 제한시간은 없다.

## 구현
- 2획 ⌞ ⌝, 3획 △ ▽, 4획 ○ □ ◇, 5획 ☆. 카드의 최소 획수 이상에 장착하며 지정 도형 제한도 지원한다.
- 컬렉션의 instanceId를 참조한다. 강화·각성·인챈트는 사본에 귀속되고 도형을 바꾸어도 유지된다.
- 기본 공격·이동·대화·생활 입력은 유지한다. 원은 기술 슬롯이므로 휴식은 자기 칸 점 터치다.
- 실행 카드 694종 중 509종의 전체 효과를 처리한다. 미지원 효과가 하나라도 있으면 장착을 막고 이유를 표시한다.
- 원본 범위·칸별 배율·조준 사거리·시전 속도·시야·장애물·유령화 판정을 사용한다. 환경 변화는 공통 속성 라우터를 통한다.
- 기술 구성에서 범위와 연습선을 확인할 수 있다. 재료 선택과 강화 전후 값, 인챈트 교체를 별도 공방 화면에서 보여준다.
- 잔화 3종을 공방 제작 풀에 추가했다. 3획 일반식, 같은 피해의 2획 약식, 5획 별 전용 광역 성식이다. 공통 family로 중복 장착과 대기시간 우회를 막는다.
- 구 세이브의 보유 카드·강화·각성 투자를 보존하고, 새 도형 슬롯을 초기화한다. 기존 장착 슬롯 버전도 이전한다.

## 초기 수치
- 마나 최대 3, 두 턴마다 1 회복. 모든 기술은 최소 마나 1과 행동 1턴을 사용한다.
- 비용은 원본 또는 magic_mana. 재사용은 기본 비용 × 2턴 또는 magic_cooldown. 사용 행동 이후 이 대기시간이 남는다.
- 빠름은 즉시, 보통은 행동 턴, 느림은 두 번째 턴에 판정한다. 예약한 칸에서 벗어나면 피할 수 있다.
- 동일 마법의 사본·약식·각성판은 대기시간을 공유한다. 맵 이동과 저장으로 초기화하지 않는다.
- 적이 보이거나 시전 중이면 기술 구성 및 공방 투자를 변경할 수 없다.

## 강화와 인챈트
- 위력: 단계 +1. 기본 수치 +12%, 최소 +1. 수식형 공격에도 최종 기본값에 적용하며 체력 지불량은 늘리지 않는다.
- 효율: 마나 −1, 최대 1회, 최소 비용 1.
- 순환: 재사용 −1턴, 최대 2회, 최소 재사용 1.
- 사거리: 조준 거리 +1칸, 최대 2회.
- 재료는 1 + floor(해당 강화 단계 / 3)장. 위력은 카드만, 나머지는 시간의 조각 5 × (해당 단계 + 1)도 쓴다.
- 자기 자신, 장착 중인 카드, 저주·빙의·임시 카드는 재료에서 보호한다. 중복·사라진 재료·자원 부족은 전체 거래를 취소한다. 분해 환급은 발생하지 않는다.
- 기존 5강 각성 문턱, 각성 후 공격 30강·그 외 10강 상한을 유지한다. 수치 효과 없는 기술은 위력 강화 대신 순환·효율·인챈트를 사용한다.
- 인챈트는 사본당 하나. 잔불(적중 시 화상 2), 보호(방어 3), 소생(재생 1). 시간의 조각 12와 가공 재료 2개로 새기며 교체 시 이전 효과는 없어진다.
- 상점의 카드 판매와 이전 세이브의 미판매 카드 슬롯을 제거했다. 소유 카드는 건드리지 않는다.

## 손패 효과의 새 역할
| 원본 | 필드 효과 |
| --- | --- |
| draw / return-hand-to-deck / draw-if-color | 다른 장착 기술의 대기시간 단축. 드로우당 최대 2턴, 색 조건 유지 |
| exhaust-self / return-self-to-hand | 재사용 +6턴 / −1턴 |
| damage-per-hand / heal-per-hand | 준비된 다른 장착 기술 수에 비례 |
| damage-low-hand | 준비된 다른 기술이 적으면 피해 두 배 |
| damage-per-cards-played | 최근 3턴 사용 기술 수에 비례 |
| next-card-double / this-turn-amp | 4턴 내 다음 기술의 공격·방어·회복 위력 증폭, 한 번만 사용 |
| hand-cost-down | 4턴 내 다음 기술 마나 감소, 최소 1 |
| next-turn-energy | 다음 턴 마나 회복, 최대 3 |

## 데이터 확장
카드의 magic_family, magic_strokes, magic_glyphs, magic_mana, magic_cooldown, magic_effects, magic_role로 기존 카드와 별도의 역할을 지정할 수 있다. magic_effects가 있으면 필드에서 기존 effects를 대체한다. 도형은 gesture-catalog의 경로·허용 오차·획수를 공유하고 기술 슬롯 목록에 등록한다. 원본 instant는 무시간 행동으로 옮기지 않는다.

## 시간
남은 시간에 따른 행동 차단과 종료를 제거했다. 저장 필드 remainingTime은 구 저장 호환용 0이다. 낮밤·작물·우편·마나 회복은 기존 세계 시계를 사용한다. 시간 단축 카오스는 진열·선택·구매·도전 점수에서 은퇴했다. 사망과 수동 종료는 유지한다.

## 남은 포팅
- 빙의·변신, 설치물, 카드별 지속 성장과 일부 특수 효과.
- 타마모 변신은 원래 기술을 봉인하고 수행 여우 전용 5개 기술을 제공한다. 해제는 카시스에게 찾아가 대화로 부탁한다. 본래 기술과 여우 기술 양쪽의 강화·각성·인챈트·배치를 보존한다. 여우 기술도 공방에서 성장하며, 해제 후 재변신해도 이어진다. 변신 중 얻은 일반 카드도 보존한다. 상세: status-transform-port.md.

동료 포팅은 이번 버전에서 제외한다. NPC 교류는 별도 방식으로 설계한다.
- 유물 사용/피격/처치 트리거와 기술 사용 연결.
- 다음 항목은 별도 기획 확인 후 진행한다. 모든 카드의 전환 완료를 의미하지 않는다.
- 실제 모바일 화면과 손가락 입력 검수. 현재 연결 가능한 브라우저가 없어 실행하지 못했다.
